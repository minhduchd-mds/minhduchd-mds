# Ecosystem Roadmap

## P0 — production reliability

- Close `desygn-ai` coverage/CodeQL and rationalize serverless API count.
- Give `open-design` durable TaskGraph/checkpoint/resume primitives.
- Validate CI runner availability for private flagship repositories.
- Rotate/revoke any credentials historically committed in `Chat-hub`.

## P1 — platform contracts

- Adopt `product.manifest.json` in each flagship repository.
- Define Design IR contract between `AI-design.tools`, `Design-hub` and `desygn-ai`.
- Expose bounded design tools via MCP.
- Create common artifact/evidence envelope for agent-generated outputs.
- Add OpenTelemetry-compatible trace IDs across orchestrated tasks.

## P2 — product differentiation

- `desygn-ai`: evidence-first design diff → patch → verify loop.
- `Design-hub`: graph relationships between principle/pattern/component/project/decision.
- `GenBI`: Metric Contract + typed Query AST + cost estimator.
- `Chat-hub`: approvals/incidents/agent-task inbox.
- `Tracking`: real event adapter + geofence + history playback.
- `Dashbord-odo`: real metric registry + drill-down + anomaly explanation.

## P3 — portfolio quality

- Consolidate duplicate repositories.
- Archive obsolete learning/demo repositories.
- Keep 8–12 flagship/active projects discoverable from the profile.
